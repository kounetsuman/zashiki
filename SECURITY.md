# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability, **do not create a public Issue**. Instead, please contact us through GitHub's private reporting feature.

- Report it from the repository's **Security** tab → **Report a vulnerability** (Private Vulnerability Reporting).

When reporting, it helps if you can include the following as far as possible:

- The type of vulnerability and the estimated scope of impact
- Steps to reproduce (a minimal PoC is ideal)
- The affected version / commit

## Response Policy

- After receiving your report, we will review its contents as soon as possible and respond with the status.
- Until a fix is in sight, we ask that you refrain from publicly disclosing the details (responsible disclosure / coordinated disclosure).

## Supported Versions

We target the latest published version (as this project is under active development, in principle only the latest version is supported).
