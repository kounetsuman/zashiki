# NOTIFICATION

Use the 🔔 (notification) icon at the far right of the footer to check messages from zashiki. A count badge appears on the icon when there are unread items.

- Clicking the icon opens the **NOTIFICATION view**, which lists notifications newest first. Opening the view marks unread items as read.
- New notifications also appear briefly as a **toast** at the bottom right of the screen. They remain in the list after the toast disappears.
- Dismissible notifications can be removed with the ✕ in the list. Non-dismissible ones (such as the restart-required notice below) disappear automatically once their cause is resolved.

## Current notifications

- **Configuration file restart required**: When you change the org (organization) makeup in `repos.conf`, a "please restart" notification stays visible (it doesn't disappear until you restart). Color changes take effect immediately, so this notification isn't shown for them. See "repos.conf and org colors" for details.

In the future, update announcements and release notes are also planned to appear here.
