# Navigation area

Down the far left of the window is a vertical activity bar (VS Code style) whose icons switch views. This shows sub-views one at a time.

- The icons are **single-select**. Only one sub-view can be shown at a time; there is no split view. The selected icon is colored.
- The icons and their views are as follows:
  - Explorer (`Ctrl+Alt+E`) — **EXPLORER**
  - Search (`Ctrl+Alt+F`) — **SEARCH**
  - Source Control (`Ctrl+Alt+G`) — **SOURCE CONTROL**
  - Notifications (`Ctrl+Alt+N`) — **NOTIFICATION** (a count badge appears when there are unread items)
- Clicking the icon of the visible view again (or pressing the same `Ctrl+Alt+<key>` again) closes that view.
- Which view was open (including the closed state) is saved in the browser and restored the next time you start up.
- **Help** (`Ctrl+Alt+H`) and **Settings** (`Ctrl+Alt+S`) are pinned at the bottom of the bar; each opens a modal dialog rather than a switchable sub-view.
- **SESSION LIST is always pinned** and is not part of this switching (it has no icon in the activity bar).
