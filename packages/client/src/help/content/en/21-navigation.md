# Navigation area

At the far right of the footer (status bar) at the bottom of the screen is a row of icons for switching panels. This shows sub-panels one at a time.

- The icons are **single-select**. Only one sub-panel can be shown at a time; there is no split view. The selected icon is colored.
- The icons and their panels are as follows:
  - Explorer (`Ctrl+Alt+E`) — **EXPLORER**
  - Search (`Ctrl+Alt+F`) — **SEARCH**
  - Source Control (`Ctrl+Alt+G`) — **SOURCE CONTROL**
  - Notifications (`Ctrl+Alt+N`) — **NOTIFICATION** (a count badge appears when there are unread items)
  - Help (`Ctrl+Alt+H`) — this help
- Clicking the icon of the visible panel again (or pressing the same `Ctrl+Alt+<key>` again) closes that panel.
- Which panel was open (including the closed state) is saved in the browser and restored the next time you start up.
- **SESSION LIST is always pinned on the left** and is not part of this switching (it has no icon in the footer).
