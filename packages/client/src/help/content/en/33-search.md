# SEARCH

Search text across all repositories under `repos.conf`. Open it with the 🔍 icon in the footer or `Ctrl+Alt+F`.

- Type a term in the input field and press **Enter** to search (an empty query does nothing).
- Three toggles let you narrow the search.
  - `Aa`: Match case
  - `ab`: Match whole word
  - `.*`: Treat as a regular expression
- Results appear as a "file > matching line" tree. Click a file row to expand or collapse it.
- Clicking a matching line lets you view that file in the **VIEWER**.
- The count is shown as "N results (N files)". If there were too many and results were truncated, that is noted. Zero matches shows "No results".
