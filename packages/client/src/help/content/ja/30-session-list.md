# SESSION LIST

セッションは org（`repos.conf` 由来のグループ）ごとに折り畳んで表示します。見出しの `▼` / `▶` をクリックで開閉、`(件数)` はその org のセッション数です。org 見出しの色は `repos.conf` で指定できます（「repos.conf と org の色」を参照）。

行はダブルクリック、または `↑` / `↓` でフォーカスを移して `Enter` でその端末に切り替わります（シングルクリックはフォーカス枠を当てるだけで、重いセッションへの誤爆を防ぎます）。アクティブな窓は行全体の薄いハイライトで、選択中はそれより少し強いハイライトで示します。

## 状態アイコン

各行の先頭アイコンが今の状態です。

- `!` 応答待ち（あなたの入力待ち）
- `•` 実行中
- `•+🤖` サブエージェント実行中（実行中アイコンにロボットのバッジが重なる）
- `✔︎` アイドル（完了・待機）
- `▮` claude が動いていない（zsh など素の端末）
- `·` 不明（copy-mode 等で判定を保留）

行には状態アイコンと会話の要約タイトルが出ます。org 名は折り畳み見出しで分かるので行には重ねて出しません。
