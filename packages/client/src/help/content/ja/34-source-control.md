# SOURCE CONTROL

git の変更をステージング / コミットします（VSCode の SOURCE CONTROL 風）。フッタの ⑂ アイコン、または `Ctrl+Alt+G` で開きます。org → リポジトリ → セクション（Staged / Changed）→ ファイルのツリーです。

- 行右端のボタンは常に見えています。
  - ファイル行: Changed は `+`（ステージ）、Staged は `−`（アンステージ）。
  - リポジトリ行: `+` で全ステージ（`git add .`）、`−` で全アンステージ（`git reset .`）。
  - `⧉` でそのファイルの絶対パスをコピーします（「copied!」が一瞬出ます）。
- ファイル名のクリックで、そのファイルを外部エディタ（`ZK_EDITOR`）で開きます。ダブルクリックで差分をタブに開きます。
- 差分タブは GitHub 風で、インライン ⇄ 左右のトグルを備えます。Staged と Changed は別々の差分として開きます。バイナリや極端に大きい差分は表示せず、「エディタで開く」を出します。
- コミットメッセージ欄は**展開中のリポジトリの中だけ**に出ます（リポジトリ 1 つにつき 1 欄）。`⌘Enter` / `Ctrl+Enter` でコミットします（変換確定の Enter は無視）。ステージが空なら Commit は押せません。
- ステータス色: 追加 A=緑 / 変更 M=黄 / 削除 D=赤 / リネーム R=シアン / 未追跡 ??=青。
- ヘッダの `↻` で取得し直します（取得中はスピナー、失敗時は `⚠` にホバーで原因）。初回取得中はツリーの代わりにスピナー、変更が無ければ「変更なし」を出します。
