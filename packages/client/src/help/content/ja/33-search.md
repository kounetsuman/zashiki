# SEARCH

`repos.conf` 配下の全リポジトリを横断してテキスト検索します。フッタの 🔍 アイコン、または `Ctrl+Alt+F` で開きます。

- 入力欄に語を打って **Enter** で検索します（空のクエリでは検索しません）。
- 3 つのトグルで絞り込めます。
  - `Aa`: 大文字・小文字を区別する
  - `ab`: 単語単位で一致させる
  - `.*`: 正規表現として扱う
- 結果は「ファイル > 一致行」のツリーで出ます。ファイル行のクリックで開閉します。
- 一致行をクリックすると、そのファイルを **VIEWER** で閲覧できます。
- 件数は「◯件（◯ファイル）」で表示します。多すぎて打ち切った場合はその旨が付きます。一致ゼロは「結果なし」です。
