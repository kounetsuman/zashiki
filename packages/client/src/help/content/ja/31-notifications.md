# NOTIFICATION

フッタ右端の 🔔（通知）アイコンから、zashiki からのお知らせを確認できます。未読があるとアイコンに件数バッジが付きます。

- アイコンをクリックすると **NOTIFICATION パネル**が開き、通知が新しい順に一覧表示されます。パネルを開くと未読は既読になります。
- 新しい通知は画面右下に**トースト**でも数秒表示されます。消えても一覧には残ります。
- 消せる通知は一覧の ✕ で消せます。消せない通知（下記の再起動要など）は、原因が解消すると自動で消えます。

## 今出る通知

- **設定ファイルの再起動要**: `repos.conf` の org（組織）構成を変えると、「再起動してください」という通知が出続けます（再起動するまで消えません）。色の変更は即時反映されるのでこの通知は出ません。詳しくは「repos.conf と org の色」を参照。

将来的に、アップデートの案内やリリースノートもここに表示される予定です。
