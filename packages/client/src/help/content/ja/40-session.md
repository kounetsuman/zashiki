# SESSION

メインエリアで、選択中のセッションの端末（Claude の出力）と会話ヘッダを表示します。表示するセッションは **SESSION LIST** から選びます（このパネル自体の開閉ボタンはありません）。

## 端末の操作

- 修飾キーなしのドラッグでテキストを選択すると、自動でコピーします。右クリックは単語を選択してコピーします。
- `Alt+ドラッグ`は tmux のマウス操作（ペイン選択・copy-mode など）に渡します。
- ホイールスクロールは tmux の copy-mode に入ります（スクロールバックは tmux が持ちます。「SESSION LIST」も参照）。
- `Shift+Enter` は改行を送ります（そのままの Enter は Claude へ送信）。

## 会話ヘッダ

- タイトルをクリックするとその場で編集できます。`Enter` で確定、`Escape` で取り消し、フォーカスを外すと確定します（変換確定の Enter では確定しません）。
- 手動で付けたタイトルが最優先、無ければ自動要約、それも無ければ窓名を表示します。
- セッションを閉じる（kill）操作はここには置かず **SESSION LIST** に集約しています。`Cmd+N` で新規セッションを作れます。
