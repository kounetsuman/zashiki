# 組織メモ

org ごとに自由記述の Markdown メモを持てます。その org が何か（顧客か内部か）、リポ群の位置づけ、チケットの接頭辞などを書き留める場所です。

## メモを編集する

SETTINGS → 組織 を開き、org を選んでメモ欄に入力し、**メモを保存** を押します。空にすると削除されます。

- メモは org ごとに 1 ファイル `~/.zashiki/notes/<org>.md`（`repos.conf` の隣）に保存されます。
- org のキーはその識別子（末尾ディレクトリ名）で、色やエイリアスと同じキーです。

## 反映のタイミング

- **保存は即時反映**され、開いている全ウィンドウに伝わります（保存と同時にサーバがメモを配信します）。
- `~/.zashiki/notes/<org>.md` をエディタで直接編集することもできます。zashiki がディレクトリを監視し、外部編集をライブで取り込みます。
