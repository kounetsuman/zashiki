# VIEWER

**EXPLORER** / **SEARCH** で開いたファイルを閲覧します（閲覧専用。編集は claude code に任せます）。メインエリア上部のタブとして開きます。

- 行番号付き・拡張子から推定したシンタックスハイライト（暗い one-dark テーマ）で表示します。
- Markdown（`.md` / `.markdown` / `.mdx`）は、1 つのペイン内でコード / プレビューをトグルできます（生 HTML はエスケープして描画）。
- Markdown プレビューを開いてもリポジトリ外の画像（`https://` の URL など）は取得しません。代わりに代替テキストとホスト名のボタンを表示し、クリックした画像だけを読み込みます。
- リポジトリ外から何かを読み込む Mermaid 図（`https://` の URL を持つ画像ノードなど）は、プレビューを開いても描画しません。代わりに読み込み先のホスト名を示すボタンを表示し、クリックした図だけを描画します。
- CSV / TSV（`.csv` / `.tsv` / `.tab`）はテーブルとして開きます（列ごとに色分け・数値列は右寄せ・先頭レコードを見出し行として扱います）。見出しのクリックで並べ替え（昇順 → 降順 → ファイルの順）、ツールバーで生テキスト表示に戻せます。
- 画像・動画・PDF（`.pdf`）はテキストでなく描画した状態で表示します（リポジトリから開いた時も Finder からドロップした時も同じです）。
- ヘッダの折り返しアイコン（コード表示中に出ます）で長い行をペイン幅で折り返します。もう一度押すと横スクロールに戻ります。選んだ状態はどのファイルを開いても引き継がれます。
- ヘッダ左端の `⧉` でそのファイルの絶対パスをコピーします（「パスをコピーしました」が一瞬出ます）。
- claude code などによる外部からの変更は一定間隔のポーリングで自動的にライブ反映します（手動更新は不要です）。
- ファイルの編集・保存はできません。補完・定義ジャンプ・ミニマップなどの IDE 機能も対象外です。
