# EXPLORER

`repos.conf` に登録した全リポジトリを、org → リポジトリ → フォルダ / ファイルの折り畳みツリーで表示します。フッタの 🗂 アイコン、または `Ctrl+Alt+E` で開きます。

- フォルダをクリックすると**その場で 1 段だけ**展開します（開いた時に直下だけ読み込む遅延展開）。
- ファイルをクリックすると、そのファイルを **VIEWER**（メインエリアのタブ）で閲覧できます。
- 各行はディレクトリを先に、続けてファイルを名前順で並べます。`.git` ディレクトリは一覧から除きます。
- リポジトリ名の左のドットは org 色です（org 帰属の目印。「repos.conf と org の色」を参照）。
- ヘッダの `↻` で一覧を読み込み直します。読めなかったフォルダ（権限不足・不在など）は、その行の下にエラーを表示します。
