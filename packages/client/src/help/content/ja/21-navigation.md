# ナビゲーションエリア

画面左端に縦のアクティビティバー（VS Code 風）があり、そのアイコンでビューを切り替えます。ここでサブビューを 1 枚ずつ表示します。

- アイコンは **単一選択** です。表示できるサブビューは常に 1 枚だけで、分割表示はしません。選択中のアイコンには色が付きます。
- 並ぶアイコンと対応ビューは次のとおりです。
  - エクスプローラー（`Ctrl+Alt+E`）— **EXPLORER**
  - 検索（`Ctrl+Alt+F`）— **SEARCH**
  - ソース管理（`Ctrl+Alt+G`）— **SOURCE CONTROL**
  - 通知（`Ctrl+Alt+N`）— **NOTIFICATION**（未読があると件数バッジが付きます）
- 表示中ビューのアイコンをもう一度クリック（または同じ `Ctrl+Alt+<キー>` をもう一度）で、そのビューを閉じます。
- どのビューを開いていたか（閉じている状態も含めて）はブラウザに保存され、次回起動時に復元されます。
- **ヘルプ**（`Ctrl+Alt+H`）と **設定**（`Ctrl+Alt+S`）はバー下部に固定され、切替サブビューではなくモーダルダイアログとして開きます。
- **SESSION LIST は常に固定表示**で、この切替の対象ではありません（アクティビティバーにアイコンを持ちません）。
