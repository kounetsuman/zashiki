# VIEWER

**EXPLORER** / **SEARCH** で開いたファイルを閲覧します（閲覧専用。編集は claude code に任せます）。メインエリア上部のタブとして開きます。

- 行番号付き・拡張子から推定したシンタックスハイライト（暗い one-dark テーマ）で表示します。
- Markdown（`.md` / `.markdown` / `.mdx`）は、1 つのペイン内でコード / プレビューをトグルできます（生 HTML はエスケープして描画）。
- ヘッダ左端の `⧉` でそのファイルの絶対パスをコピーします（「パスをコピーしました」が一瞬出ます）。
- claude code などによる外部からの変更は一定間隔のポーリングで自動的にライブ反映します（手動更新は不要です）。
- ファイルの編集・保存はできません。補完・定義ジャンプ・ミニマップなどの IDE 機能も対象外です。
